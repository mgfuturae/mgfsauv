Confidentialité

MANAGE FUTURAE pour Windows — version du Microsoft Store

Vos données restent sur votre ordinateur

MANAGE FUTURAE est une application installée sur votre ordinateur. Vos fiches, votre comptabilité, vos documents joints et vos sauvegardes y sont rangés, chiffrés par votre mot de passe. Ce mot de passe n'est écrit nulle part et ne quitte jamais votre ordinateur. Aucune de vos données n'est envoyée à l'éditeur : il n'y a pas accès.

Ce que l'application ne fait jamais

  • Aucune publicité.
  • Aucune statistique d'utilisation, aucun rapport d'erreur envoyé.
  • Aucun cookie.
  • Aucune revente ni aucun partage de vos données.

Ce qui passe par Internet, et pourquoi

Seules quelques fonctions ont besoin d'Internet. Chacune n'envoie que le strict nécessaire, et chaque service contacté voit l'adresse Internet (IP) de votre connexion.

  • Feuille de route du matin — météo, qualité de l'air, pollens, prix des carburants : le code postal et la ville de votre adresse (jamais la rue) sont envoyés à Open-Meteo pour situer votre ville ; puis la position du centre de la ville est envoyée à Open-Meteo et au service public des prix des carburants. Chaque rubrique se désactive dans Paramètres.
  • Titres d'actualité : un flux public est lu ; rien n'est envoyé.
  • Cours de bourse : si vous avez saisi le code d'une valeur, ce code est envoyé à Yahoo Finance, une fois par jour, pour obtenir son cours. Jamais les quantités ni les montants.
  • Révision du loyer : l'indice de référence des loyers est lu sur le site de l'INSEE ; rien n'est envoyé.
  • Démonstration : la liste des accès de visite est lue sur GitHub ; ce que vous tapez est vérifié sur votre ordinateur.

Le réseau de la maison

L'analyse du réseau domestique (rubrique Domotique) reste dans votre maison : rien n'est envoyé sur Internet.

Le microphone

Il sert seulement à enregistrer des messages dans « Mes Souvenirs ». Les enregistrements restent sur votre ordinateur, chiffrés.

Désinstaller

Désinstaller l'application efface ses données de l'ordinateur. Avant, faites « Sauvegarder tout » vers une clé USB ou vos Documents.

Vos droits

Vos données sont sur votre ordinateur : vous les consultez, les corrigez et les effacez vous-même, dans l'application.
